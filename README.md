# SLua.dev

SLua.dev is an unofficial documentation site for the lua scripting language of Second Life. SLua is a fork of Luau.

The goal with this project had been to experiment with how good SLua documentation could look like. So it is encouraged to test drastic changes in your own forks if you want to. I wanted a space where I would be free to try wild ideas with the design and user experience, aiming for the most effective teaching material and scripting reference.

However as the project evolves and matures with contributions this could change into a stable documentation site if people are happy with it.

Official documentation would eventually be available at: https://create.secondlife.com/
